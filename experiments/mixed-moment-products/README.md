# Mixed moment-product experiment

[Report](../../docs/mixed-moment-products.md): FP32 products with FP64 sums
produce ten independently validated meshes across five pairs, but change the
optimization trajectories and quality. The graded scan is slower; torus and
cavity worst-element quality decreases. The variant is not adopted.
Raw results, the initial invalid plate CLI invocation, corrected pair, and
independent geometry checks are retained as release evidence.
