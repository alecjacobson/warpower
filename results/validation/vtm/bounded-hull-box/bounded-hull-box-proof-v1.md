This private filter reuses two existing certified primitives; it does not introduce a new roundoff formula.

For original binary32 face vertices a,b,c, `halfspace` encloses each component of the exact real normal n=(b−a)×(c−a) in its existing Ball64 interval. A finite interval [v−e,v+e], e≥0, with v≥e proves n_i≥0; v≤−e proves n_i≤0. If neither holds for any component, `maximum_corner` is unavailable and all boxes use the existing checker. An exactly zero component may choose either endpoint. Finite and nonnegative-error guards exclude unsupported interval values.

For an ordered finite box [lo,hi], choose q_i=hi_i for a certified nonnegative component, and q_i=lo_i for a certified nonpositive component. For every real x in this box, n·(x−a)≤n·(q−a). The selected corner consists of original stored binary32 endpoints, with no rounded center or extent calculation.

The existing `_bounded_predicates.orientation_filter(a,b,c,q)` bounds the exact determinant n·(q−a). The new filter accepts only when its value is strictly less than minus its error. This proves the corner, the whole box and every contained original site lie strictly inside the oriented halfspace. Its supported coordinate range and underflow/FTZ allowance are unchanged, as verified by `benchmarks/bounded_predicate_proof.py`. Both box endpoints must also meet that range gate, and reversed boxes are rejected. Nonfinite/unsupported/uncertain cases return false and retain the old interval/exact traversal. All calling modules disable fast math and floating-point contraction.

The normal bounds are already prepared by the existing kernel, so only a per-face integer corner mask and the per-node filter are added. No persistent storage, graph nodes, host decisions, cross-frame proof or public trust mask is introduced. Existing exact coordinate-plane root support runs first. The prototype affects only private VTM support; it is not adopted. Rational eight-corner checks, captured tests, decision audits and complete measurements remain required.
