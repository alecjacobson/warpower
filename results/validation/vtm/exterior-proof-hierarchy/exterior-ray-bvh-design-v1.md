# Conservative hierarchy proof prototype (issue239)

The plane-only prototype preserves all three pilot geometries and scheduler work exactly, but uniform8K still takes34.04s on its first diagnostic replay. The original v2 recovery run took35.38s. These are isolated pilot observations, not an interleaved performance claim. Plane-only analytic/differential/refit tests:24passed.

The next prototype prunes the rational-centroid winding traversal using exact binary32 node bounds and outward float64 error balls. For each node and axis, `centroid_row` bounds `4*box - sum(tet vertices)` without rounding the centroid. Flip the slab endpoints/sign for negative direction components, leaving strictly positive denominators. Reject a node only if an upper exit numerator is provably negative, or any entry_i*d_j - exit_j*d_i is provably positive. Otherwise visit it. There are no divisions; the existing ball operations conservatively bound each product/difference. Fixed directions have finite nonzero integer components. Finite binary32 coordinates keep these degree-two quantities and their error bounds within normal binary64 range. Current BVH bounds are exact min/max of the original surface coordinates after refit.

A rejected node cannot intersect the forward ray, so no enclosed triangle can contribute a crossing. Visited triangles still use the original filtered/exact dyadic determinant predicate; unresolved crossings remain inconclusive and the same three directions are tried. Plane separation retains exact original predicate checks on every triangle whose exact box overlaps the tetrahedron. Traversal is bounded by the preallocated acyclic escape hierarchy.

Semantic distinction: the old exhaustive ray reports coplanarity with an infinite triangle plane as ambiguous even when the finite triangle lies far from the ray. The new certified box exclusion can skip that harmless ambiguity. Thus ray diagnostics are not promised bitwise identical for arbitrary degenerate inputs. The whole-cell exterior claim remains geometric and conservative; no rounded centroid or approximate sign is accepted. Add an explicit disjoint-coplanarity regression and a Fraction oracle for box intersections, along with extreme-scale/degenerate tests, real captured proofs, full geometry and device-loop validation. This is not a production change.
