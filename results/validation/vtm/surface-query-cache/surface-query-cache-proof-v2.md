# Exact query reuse with a device surface generation

Version2 retains v1's exact center/nearest-cutoff keys, per-consumer double buffers, original miss paths, strict result bits and bounded-probe fallback. Every SurfaceDomain now receives a private int64 generation at construction, before its initial refit. Each refit advances the generation on the caller's stream before changing safe points, hierarchy or geometry. All supported position changes require refit; surface topology is fixed by setup. A cache lookup additionally requires its completed previous generation to match the current generation.

The single-thread increment saturates at INT64_MAX. At that value every lookup is a miss, permanently disabling reuse rather than wrapping onto an old generation. The loop test forces this state. A separate build kernel records the current generation after query evaluation and device snapshot copies. Failed classification leaves an empty table. The query kernel never reads a partially built current table or current result buffer.

There is no global callback list for invalidation and no dependency on a fresh-solve reset. Exact query results may remain valid across point trajectories when the surface generation is unchanged; current cell geometry, quality, retention thresholds and input validity are always recomputed. Different consumers retain separate caches so they do not share results produced in different compiled calling contexts. There is still no host input comparison/readback or allocation during execution.

This is private prototype code. Production integration must retain ordinary public diagram/Delaunay/extraction/VTM defaults and enable caches only in the complete mesher's private consumers. SurfaceDomain's generation requires eight device bytes and one small refit launch. V1's measured cache arrays cost about42.2MB at4k sites across seven consumers; v2 additionally stores a saved generation per cache. Allocation cost and complete replay timing must include these changes. Cold/warm original-kernel comparisons, captured refit/failure/recovery/saturation, complete geometry and standalone/nonregression audits remain the adoption gates.
